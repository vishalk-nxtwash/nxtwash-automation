# Memberships Automation Improvement Plan

Basis: `reports/memberships_evidence_based_coverage.md`. Only manual cases marked Partially Automated, Incorrectly Automated, or Not Automated are included.

## Coverage Projection

- Current full coverage: 26/115 = 22.6%
- Coverage after Phase 1: 49/115 = 42.6%
- Coverage after Phase 2: 80/115 = 69.6%
- Coverage after Phase 3: 109/115 = 94.8%
- Phase 4 is excluded from near-term projected coverage because these cases need environment, data, or infrastructure support.

## Phase Summary

| Phase | Items | Strategy |
|---|---:|---|
| Phase 1 – Critical Fixes | 23 | Fix incorrect automation and add low/medium-effort P1 gaps with direct coverage impact. |
| Phase 2 – Coverage Improvements | 31 | Complete partial tests and fill common UI/search/filter/validation gaps. |
| Phase 3 – New Automation | 29 | Add new CRUD, export, permissions, and broader business workflows. |
| Phase 4 – Advanced Scenarios | 6 | Plan environment-heavy scenarios such as large data, concurrency, slow network, audit, restart. |
