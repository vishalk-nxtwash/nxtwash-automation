- Duplicate manual coverage: UI/list cases overlap for table visibility, edit action, pagination, page-size dropdown, and download visibility/export. Consolidate expected results or keep one UI and one behavior test.

## 9. Risk Assessment
- Environment dependency: tests operate against staging data and can be affected by existing duplicate site records.
- Test data dependency: active/inactive filtering needs known inactive fixture data; edit tests need isolated disposable records.
- Framework limitation: current Selenium POM needs stronger React-select handling or API-backed setup to avoid UI setup failures.
- CI/CD risk: long UI create flows are slow and brittle; move heavy setup to API where the behavior under test is not the create form itself.
- Google Sheet limitation: CSV export does not prove hidden/grouped/filtered row inclusion.
