## 8. Risk Assessment
- Staging data dependency: existing package names and site options must remain stable (`Plus Wash`, `VK Test carwash 2`).
- Download verification requires browser download directory configuration and CSV/XLS parsing utility.
- Permissions require separate users/roles and predictable access-control fixtures.
- Advanced edge cases require framework extensions: multi-browser sessions, network interception/throttling, audit API access, and large-data setup.
- Current create/save helpers exist in the POM but are not exercised by a reliable creation test; use API setup where creation itself is not under test.
